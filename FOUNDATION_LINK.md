# FOUNDATION LINK

This repository is the public portable layer of the private instrument workshop.

It implements project-independent operational contracts derived from SYSTEM-FOUNDATION.

Primary bindings:
`STATE → TRANSITION → PROVENANCE → VERIFICATION → HISTORY → RECOVERY`

No project data, private identifiers or internal experiment state belongs here.

Publication boundary:
`PRIVATE TOOL → ISOLATE → SANITIZE → VERIFY → PUBLIC TOOL`

Guardian is the publication/security gate.
