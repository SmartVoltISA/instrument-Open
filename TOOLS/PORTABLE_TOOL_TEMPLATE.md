# Portable Tool — шаблон независимого инструмента

> Этот шаблон предназначен для переноса инструмента между средами без переноса данных исходного проекта.

## 1. Название

`<TOOL_NAME>`

## 2. Назначение

Кратко: какую одну основную функцию выполняет инструмент.

## 3. Независимость

Инструмент не должен требовать конкретного прикладного проекта.

**Источник данных:** `USER_DATA_INPUT`

**Результат:** `TOOL_OUTPUT`

## 4. Подключение

1. Установить необходимые зависимости.
2. Подать собственные данные пользователя во входной интерфейс.
3. Запустить инструмент.
4. Получить результат.
5. Проверить результат.

## 5. Использование

```text
USER_DATA_INPUT
      ↓
   TOOL_NAME
      ↓
  TOOL_OUTPUT
      ↓
   VERIFY
```

## 6. Интерфейс

**Вход:** `<описание входа>`

**Выход:** `<описание выхода>`

**Ошибки:** `<описание ошибок>`

## 7. Проверка

Минимальный тест должен использовать нейтральные тестовые данные и не содержать данных исходного проекта.

## 8. Что НЕ переносится

- реальные данные исходного проекта;
- приватные конфигурации;
- секреты;
- внутренние пути;
- проектные идентификаторы;
- проектная бизнес-логика, если она не является частью самого инструмента.

## 9. Точка адаптации

Пользователь заменяет только:

`USER_DATA_INPUT = <свои данные>`

Остальная логика инструмента остаётся неизменной, если его интерфейс это допускает.
