# Git

## Назначение

Система контроля версий для фиксации изменений, сравнения состояний и возврата к предыдущим состояниям.

## Что принимает

- файлы;
- изменения файлов;
- сообщения commit;
- ветки и метки.

## Что делает

Фиксирует последовательность состояний и связывает каждое изменение с историей.

## Что выдаёт

- commit;
- diff;
- историю изменений;
- возможность восстановления состояния.

## Связи

Git является связующим слоем между рабочими файлами, проверками и удалённым репозиторием.

Типовая цепочка:

**редактор → Git → проверка → GitHub**

## Проверка

Инструмент проверяется сравнением состояния до и после изменения, просмотром diff и возможностью восстановить выбранное состояние.

## Практическое применение

Используется там, где необходимо сохранять историю изменений и иметь воспроизводимое состояние рабочей среды.

## Ограничения

Git фиксирует состояние, но сам по себе не доказывает корректность содержимого. Проверка результата является отдельным этапом.

## Статус

Базовый инструмент. Дата документации: 2026-08-16.
