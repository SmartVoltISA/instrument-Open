# Реестр инструментов

| ID | Инструмент | Назначение | Статус | Версия | Дата |
|---|---|---|---|---|---|

Пустая строка реестра — это нормально. Инструмент добавляется только после создания отдельного описания по шаблону.

## Правило

Не добавлять инструмент в реестр только по названию. Сначала должно существовать описание с назначением, входом, выходом и способом проверки.
