## Портируемый шаблон

`PORTABLE_TOOL_TEMPLATE.md` используется как обязательная основа для создания независимого публичного инструмента.

## Guardian

Перед переносом или публикацией применяется [`../GUARDIAN.md`](../GUARDIAN.md).

## Правило

Инструмент добавляется в реестр только после проверки независимости от конкретного проекта.

## State Anchor Adapter

`state_anchor_adapter/` реализует исполнительную часть правила внешних checkpoint из SYSTEM-FOUNDATION.

Статус пока `DEVELOPMENT`: эвристики частоты должны быть проверены на реальном наборе устройств перед переводом в `VERIFIED`.
