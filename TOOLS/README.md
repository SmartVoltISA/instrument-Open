# Каталог инструментов

Здесь находятся описания отдельных инструментов и их ролей.

## Принцип

Инструмент описывается как функциональный узел, а не как название программы.

Для каждого инструмента фиксируются:

- назначение;
- входные данные;
- действие;
- результат;
- связи;
- проверка;
- ограничения;
- версия и дата;
- обратная связь.

## Статусы

- `draft` — описание готовится;
- `tested` — инструмент проверен в конкретной конфигурации;
- `verified` — результат воспроизводим и подтверждён повторной проверкой;
- `deprecated` — инструмент больше не рекомендуется.

Статус не означает абсолютную надёжность. Он относится только к зафиксированной конфигурации и условиям проверки.

## Каталог

Инструменты добавляются сюда после заполнения единого шаблона `TOOL_TEMPLATE.md`.
