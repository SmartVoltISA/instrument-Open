# Подключение инструментов

Инструменты этого каталога являются независимыми строительными блоками. Они не требуют подключения к какому-либо конкретному прикладному проекту.

## Базовый набор

### Git

1. Установить Git.
2. Инициализировать рабочую директорию или клонировать существующий репозиторий.
3. Проверить состояние через `git status`.
4. После изменения проверить `git diff`.
5. Зафиксировать проверенное состояние через `git add` и `git commit`.

Git отвечает за локальную историю. Он не заменяет проверку содержимого.

### GitHub

1. Создать или выбрать репозиторий.
2. Связать локальный Git с удалённым репозиторием.
3. Передавать проверенные commits в удалённый репозиторий.
4. Получать сохранённые состояния обратно при необходимости.

GitHub отвечает за удалённое хранение и публикацию. Название, структура и содержимое конкретного проекта не являются частью инструмента.

### Terminal

1. Открыть терминал в рабочей директории.
2. Выполнить необходимую команду.
3. Проверить код завершения и фактический результат.
4. При необходимости передать результат следующему инструменту.

## Минимальная рабочая цепочка

**Terminal → результат → проверка → Git → GitHub**

или при редактировании:

**Editor → Git → Terminal → проверка → GitHub**

## Как использовать инструменты вместе

Инструменты соединяются по результату, а не по принадлежности к проекту.

Например:

- Terminal создаёт или изменяет состояние.
- Git фиксирует это состояние.
- GitHub сохраняет его удалённо.
- Следующий инструмент получает сохранённое состояние.

## Независимость

Этот каталог описывает только инструментальные функции. Подключение инструмента к конкретному проекту выполняется на стороне пользователя и не меняет сам инструмент.

## Правило

**Подключить инструмент — значит дать ему вход и получить проверяемый выход.**

Если инструмент невозможно проверить через его результат, описание подключения считается неполным.
