# Graph Memory Inspector v0.1

**Status:** WORKING (original test suite and validation model ported; public CI still requires a run)

## Назначение

Read-only инструмент для проверки структуры графа памяти. Он наблюдает граф и не изменяет исходные данные.

## Вход

Граф в форме:

- `nodes` — узлы с `id`, состоянием и provenance;
- `relations` — связи с `id`, `source`, `target`, `type` и provenance.

## Выход

Детерминированный список найденных структурных дефектов:

- отсутствующая или дублированная идентичность узла;
- отсутствующий provenance;
- отсутствующая или дублированная идентичность связи;
- отсутствующий источник/назначение связи;
- отсутствующий тип связи;
- дублированная сигнатура связи;
- конфликтующие состояния.

## Ключевой инвариант

**Inspection must not mutate the inspected graph.**

Проверка включает отдельный тест неизменности входных данных.

## Переносимость

Этот экземпляр очищен от данных конкретного проекта. Пользователь подставляет собственный граф в `graph` и получает собственный результат проверки.

## Проверка

Перенесён оригинальный исполняемый набор тестов без проектных данных. Локальный запуск:

```bash
cd TOOLS/graph_memory_inspector
python -m unittest -v test_inspector.py
```

Оригинальная CI-конфигурация использует Python 3.12. В публичной копии статус пока `WORKING`, пока этот набор не будет отдельно прогнан в её собственном CI.

## Материалы

- `inspector.py` — ядро;
- `test_inspector.py` — исполняемые проверки;
- `EDGE_MODEL.md` — модель first-class связи;
- `fixtures/README.md` — спецификация детерминированных тестовых случаев.

## Ограничения

Это структурный инспектор. Он не определяет истинность утверждений, не исправляет данные, не удаляет данные и не делает автоматический вывод о том, какая сторона конфликта «правильная».
