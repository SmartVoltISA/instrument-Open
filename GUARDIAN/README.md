# Guardian

Guardian — контроль границы между самостоятельным инструментом и прикладным проектом.

## Перед публикацией

Проверяется:

1. происхождение инструмента;
2. состав переносимых компонентов;
3. отсутствие проектных данных;
4. отсутствие приватных идентификаторов и секретов;
5. независимость от конкретного проекта;
6. наличие входа и выхода;
7. наличие воспроизводимой проверки;
8. сохранение provenance.

## Результат

Только после прохождения цепочки:

**SOURCE → EXTRACT → ISOLATE → SANITIZE → VERIFY → PORTABLE → PUBLISH**

инструмент может попасть в публичный слой.

## Защита проекта

Guardian рассматривает прикладной проект как источник, который нельзя переносить целиком вместе с инструментом.

**Инструмент выносится. Проект остаётся на месте.**
