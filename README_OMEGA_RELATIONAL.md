# Ω Relational Diagnostic Engine v0.1

Публичный, безопасный и предметно-нейтральный MVP диагностического инструмента.

## Что делает

Принимает ориентированный граф отношений и рассчитывает:

- входящий и исходящий поток;
- отношение `F_in/F_out`;
- накопленную память отношения;
- степень связности узла;
- эффективное число активных узлов;
- предварительную классификацию режима.

## Реляционная модель

Отношение — самостоятельный объект:

`R_ij = {strength, stiffness, connectivity, memory, flow}`

Направление не предполагается физическим законом. `R_ij` и `R_ji` могут отличаться только потому, что входные данные это показывают.

## Важное ограничение

Инструмент **не доказывает существование аттракторов, чёрных дыр, плазмы или физических законов**. Он диагностирует структуру предоставленного графа.

Статусы интерпретации:

`OBSERVED → DERIVED → MODEL → HYPOTHESIS`

## Минимальное применение

```python
from omega_relational import OmegaRelationalGraph

g = OmegaRelationalGraph()
g.add_relation("A", "B", memory=3, flow=10)
g.add_relation("B", "A", memory=1, flow=2)
g.add_relation("B", "C", memory=2, flow=4)

print(g.diagnostics())
print(g.classify())
```
